What's Possible

✓ Grain texture — Adds tactile, film-like quality

✓ Gradients — Subtle depth on sidebar and background

✓ Typography — Instrument Serif for titles, JetBrains Mono for tags

✓ Logo — SVG recreation (or we can embed actual PNG as base64)

✓ Layouts — Sidebar, accent lines, minimal, inverted

✓ Dynamic content — Title changes per essay automatically

⚠️ Limitations — Next.js OG images use Satori renderer which supports most CSS but not all (e.g., no CSS filters, limited blend modes). Grain needs to be SVG-based.
