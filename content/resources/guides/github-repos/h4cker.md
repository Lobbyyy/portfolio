## What it is

[h4cker](https://github.com/The-Art-of-Hacking/h4cker) is a huge collection of cybersecurity references, scripts, tools, labs and training material. Security author and trainer Omar Santos maintains it. It's free (MIT) and has over 30,000 stars on GitHub.

## What you get

- **Cybersecurity domains.** Fundamentals, offensive and defensive security, threat hunting, cloud and container security, and app security.
- **AI security.** LLM security, AI-assisted incident response and AI governance.
- **Certifications.** Roadmaps and material for CompTIA, ISC2, Cisco, cloud, Kubernetes and offensive security exams.
- **Build your own lab.** How to set up a safe practice range at home.
- **Training reference.** Cheat sheets, tool indexes and people worth following.

## How to use it

1. Open the repo and start with the section that matches your goal.
2. New to it? Build a lab first, then follow the fundamentals.
3. Studying for a cert? Go straight to the certifications folder.

## Before you use it

Practise only on your own lab, or on systems you have written permission to test. Testing anyone else's systems without permission is illegal in most countries. Some sections link to outside tools, so check each one before you run it.
