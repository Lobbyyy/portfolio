## What it is

[Trilium Notes](https://github.com/TriliumNext/Trilium) is a free, open-source note app made for large personal knowledge bases. It has about 39,000 stars on GitHub (AGPL-3.0). The original developer handed it to the community, and it now lives under TriliumNext.

## What you get

- **A deep tree.** Notes nest as deep as you like, and one note can sit in several places at once.
- **Link maps and relation maps.** See how your notes connect.
- **Scripting and a REST API.** Automate your notes.
- **Self-hosted sync.** Run your own server and reach it from any browser, phone included.
- **The extras.** Note versions, per-note encryption, Excalidraw sketches, mind maps, a web clipper and Evernote or Markdown import.

It stays fast past 100,000 notes.

## How to set it up

- **On your computer:** download it for Windows, macOS or Linux from the [latest release](https://github.com/TriliumNext/Trilium/releases/latest), unzip it and run `trilium`.
- **On your own server:** use the [Docker image](https://docs.triliumnotes.org/user-guide/setup/server/installation/docker), then open it in Chrome or Firefox.
- **On your phone:** open the server's mobile web version, or use a community app (TriliumDroid or Pocket Trilium on Android, Trinote on iOS).

## Before you use it

It's spelt "Trilium", with one L. Search for "Trillium" and you'll find other things. If you already use the old zadam/Trilium, install TriliumNext and it opens your existing database.
