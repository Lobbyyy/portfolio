## What it is

[OpenCut](https://github.com/OpenCut-app/OpenCut) is a free, open-source video editor, built as an alternative to CapCut. It has almost 100,000 stars on GitHub (MIT licence). There is no subscription, nothing locked behind a paywall, and no surprise price rise once you depend on it.

## What you get today

- **Edit in your browser.** Open [opencut.app](https://opencut.app) and start editing, with nothing to install.
- **The classic version.** The editor that works today lives at [opencut-app/opencut-classic](https://github.com/opencut-app/opencut-classic). It's the one to use right now.

## What's coming

The team is rewriting OpenCut from the ground up. The plan:

- **An MCP server**, so AI agents can plug in and edit for you.
- **Headless mode** for automation and batch rendering: many edits without opening the editor.
- **One app for desktop, mobile and browser**, from a single Rust core.
- **An editor API, plugins and a scripting tab** inside the editor.

## Before you start

The rewrite is still in progress, so the agent features aren't here yet. Use the browser editor or the classic version today, and watch the repo for the new one. The team isn't taking outside contributions while the architecture is being designed.
