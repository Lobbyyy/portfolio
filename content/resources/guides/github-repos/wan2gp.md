## What it is

[WanGP](https://github.com/deepbeepmeep/WanGP), first known as Wan2GP, is a free app by deepbeepmeep that runs open-source AI video models on your own graphics card. It has over 12,000 stars on GitHub. The project says it will never charge a licence fee, subscription or donation to run it on your own computer.

## What you get

- **Text to video.** Describe the scene and it makes the clip, with models like Wan 2.1/2.2, LTX, Hunyuan Video and MiniMax H3.
- **More than video.** Images, music, speech and 3D assets in the same app.
- **Low-end GPUs welcome.** Some models run with 4 GB of video memory, and it supports older Nvidia cards (GTX 10XX and up) and AMD cards.
- **A browser interface** with a queue, so you can line up jobs and come back later.
- **Batch and automation.** A headless mode for the command line, an API and an MCP interface for AI agents.

## How to set it up

1. Clone the repo, then run the one-click installer: `scripts/install.sh` on Linux or macOS, or double-click `scripts\install.bat` on Windows. Choose **Auto Install**.
2. Start it with `scripts/run.sh` (or `run.bat`) and open the web interface it shows.
3. On Windows there is also an experimental WanGP Manager app, and Pinokio offers a one-click install.

## Before you start

You need a computer with a graphics card. Video generation is heavy, so expect it to be slower than paid cloud tools on a small GPU. Download it only from the official GitHub repo or wangp.ai: the project says other sites using the name aren't theirs.
