## What it is

[awesome-free-apps](https://github.com/Axorax/awesome-free-apps) is a list on GitHub, kept by Axorax, with over 8,000 stars. It collects free apps for PC and mobile and puts them in one place, so you stop paying a monthly fee for something a free app already does.

## What you get

- **Sorted by category.** Audio players and recording, DJ software, music production, game engines, office suites, ebooks, PDF tools, browsers, email and a lot more.
- **Filtered by system.** There are separate lists for Windows only, macOS only, Linux only and open source only, plus a mobile version for Android and iOS.
- **Icons on every app.** Each one shows which systems it runs on, whether it's open source, and whether the maintainers recommend it.
- **A line on each app**, so you can tell if it fits before you install anything.

## How to use it

1. Open the list and pick your system from the links at the top.
2. Jump to the category you need, for example PDF tools.
3. Read the one-line descriptions and look for the ⭐ (recommended) and 🟢 (open source) icons.
