## What it is

[UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) is an open-source design skill by NextLevelBuilder, with over 150,000 stars on GitHub (MIT licence). It gives your AI agent a design brain: before it builds a page, it picks a style, colours, fonts and layout that fit what you're making.

## What you get

- **80 searchable UI styles**, from soft UI and glassmorphism to brutalism.
- **194 colour palettes**, each matched to a type of product.
- **74 font pairings**, ready to import from Google Fonts.
- **A design system generator.** Describe the project and it writes the rules: pattern, style, colours, type and the things to avoid.
- **Works beyond Claude Code.** Cursor, Codex, Gemini CLI, Copilot, Windsurf and more than 15 others.

## How to set it up

1. Copy the prompt at the top of this page into Claude Code. Or install it as a plugin: `/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill`, then `/plugin install ui-ux-pro-max@ui-ux-pro-max-skill`.
2. It needs Python 3 for its search script (no extra packages).
3. Optional, from the video: add 21st.dev's [Magic MCP](https://21st.dev/magic) for ready-made animated components. Paste its install command into Claude Code and say "install this MCP server".

Then just ask Claude to build the site. The skill turns on by itself for design work.

## Before you start

This repo is the free basic version. A paid premium version adds brand, logo and asset design, and you don't need it to use the skill.
